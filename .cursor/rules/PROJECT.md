# Erman AI — Описание проекта

## Что это

**Erman AI** — личный кабинет для автоматизации бизнес-процессов с помощью AI.
Пользователи получают набор готовых инструментов: калькуляторы, генераторы стратегий
и коммерческих предложений — без необходимости разбираться в технологиях.

Платформа ориентирована на собственников бизнеса, операционных директоров
и продажников, которые хотят быстро получить конкретный результат:
цифры, документ, готовое КП.

---

## Инструменты

### 1. Automation Calculator — Калькулятор автоматизации

Помогает понять, выгодно ли автоматизировать конкретный бизнес-процесс.

**Как работает:**
Пользователь вводит параметры процесса — сколько сотрудников, сколько часов,
стоимость ошибок, стоимость автоматизации. Система за секунду рассчитывает
экономию, срок окупаемости и выдаёт рекомендацию: автоматизировать / рассмотреть / не рекомендуется.

**Ценность:**
- Мгновенный результат (без LLM, без ожидания)
- Конкретные цифры вместо абстрактных обещаний
- Экспорт в PDF для презентации руководству (тариф Pro+)
- Кнопка "Создать КП" — переход к Proposal Generator с данными калькулятора

**Доступность:** Безлимитно на всех тарифах. PDF-экспорт — Pro+.

---

### 2. AI Strategy Generator — Генератор AI-стратегии

Создаёт персонализированную стратегию внедрения AI для конкретного бизнеса.

**Как работает:**
Пользователь отвечает на структурированные вопросы: отрасль, размер компании,
текущий уровень автоматизации, цели, бюджет, срок. AI (Claude Sonnet) генерирует
полноценный документ-стратегию с roadmap, приоритетами и конкретными следующими шагами.

**Структура документа:**
1. Executive Summary
2. Текущая ситуация и диагностика
3. Топ-3 рекомендуемых AI-решения с обоснованием
4. Roadmap внедрения по кварталам
5. Ключевые риски и митигация
6. Метрики успеха (KPI)
7. Следующие шаги на ближайшие 30 дней

**Доступность:** 3 раза/месяц бесплатно, 30/месяц на Pro, безлимит на Business.
Время генерации: 30–90 секунд.

---

### 3. Proposal Generator — Генератор коммерческого предложения

Формирует готовое профессиональное КП для клиента на автоматизацию.

**Как работает:**
Пользователь вводит данные клиента и описание решения (или импортирует из Калькулятора).
AI генерирует структурированное КП с обращением, пониманием задачи, описанием решения,
scope, сроками, стоимостью и призывом к действию.

**Выходные форматы:**
- PDF — для отправки клиенту
- DOCX — для редактирования перед отправкой

**Доступность:** 1 раз/месяц бесплатно, 10/месяц на Pro, безлимит на Business.

## Технический стек

| Компонент | Технология |
|-----------|-----------|
| Backend | Go 1.23+ (chi, pgx, goose) |
| Frontend | Next.js 15, TypeScript, Tailwind CSS, shadcn/ui |
| Database | PostgreSQL 16 |
| LLM | OpenRouter (Claude Sonnet для генерации, Gemini Flash для структуры) |
| Reverse Proxy | Nginx |
| Контейнеризация | Docker + Docker Compose |
| CMS/Лендинг | WordPress 6 |
| Object Storage | MinIO (PDF/DOCX артефакты) |
| Очереди | NATS JetStream (production) |
| Кэш | DragonflyDB (production) |
